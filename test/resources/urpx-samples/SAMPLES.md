# URPX sample documents

Worked samples vendored from [urpx-dev](https://github.com/urpx-org/urpx-dev), with any document they must be merged with, as frozen specimens. Each `.license` sidecar records the repository, branch, commit and path the bytes came from, and the SPDX headers that repository's `REUSE.toml` declares for that path.

`service-bracket-offset/` holds the urpx-dev `dev-docs/samples/service-bracket-offset/` samples for urpx-org/urpx#80 and the `test-cases/pge-e-tou-c` document they reference by `@id`, taken from the urpx commit the samples' README validates against. `urpx.service-bracket-offset-samples-test` merges each sample with it.
